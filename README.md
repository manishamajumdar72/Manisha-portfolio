# Manisha Majumdar — Portfolio

A responsive editorial-style personal portfolio built with plain HTML, CSS, and JavaScript. It has no build step or framework dependencies; the page is designed to be easy to preview, edit, and host as a static site.

## Preview locally

1. Extract this folder if it came as a ZIP.
2. Open `index.html` in a browser. For the most reliable local preview, use a simple static server (for example, VS Code Live Server).
3. Internet access is only used for Google Fonts. The site still works if those fonts are unavailable, using system fallbacks.

## Where to personalize it

- `index.html`: name, hero copy, about text, project titles/descriptions, skills, contact details, page metadata, and section content.
- `styles.css`: colors at the top in `:root`, typography, spacing, layout, animations, and responsive rules.
- `script.js`: mobile navigation, scroll effects, reveal animations, and active section highlighting.
- `favicon.svg`: the monogram favicon.

## Important content notes

The portrait and three project visuals are CSS-made placeholders, not photos or claims about Manisha's real work. Replace the portrait placeholder with an authorized photo and replace all project, biography, skills, and contact placeholders with verified details before publishing. Experience/education is intentionally not represented as factual content because no details were provided.

## Before publishing

- Add Manisha's real biography, skills, projects, education (where relevant), and contact/social links.
- Replace the CSS portrait composition with an optimized, locally hosted image and accurate alt text if a real portrait is supplied.
- Connect a real contact method or form endpoint if a working form is desired; this version deliberately does not claim to send messages.
- Update the description and Open Graph metadata to match the final content.
- Consider hosting on GitHub Pages, Netlify, or another static host.
